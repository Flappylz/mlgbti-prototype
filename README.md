# MLGBTI · 可交互原型

> 多维语言与生成式行为类型指标 (Multidimensional Linguistic & Generative Behavior Type Indicator)
> 端到端语音模型 Demo · iPhone 16 Pro Max 机型

## 做了什么

基于 PRD 完整还原了一份**可点击、可演示、可分享**的小程序原型，单文件零依赖，覆盖 5 个核心页面：

| # | 页面 | 关键体验 |
|---|---|---|
| 01 | **学术封面** | 衬线大字标题 + MLGBTI 字母标 + 四象限色卡 + 滚动确诊播报 + 大号 CTA |
| 02 | **对线规则** | 极简导览页，3 条规则，强化"压力测试"心理预期 |
| 03 | **沉浸对线** | 流体语音波形（SVG morph）+ 按住说话 + AI 抢话/震屏 + 实时声压/静默指标 |
| 04 | **声纹解析** | M·L·G·B 四维条形动画 + 数字滚动 + 等宽字体技术感 |
| 05 | **MLGBTI 确诊** | 16 人格随机 / 指定结果 + SVG 极简画像 + 锐评&发言 + 一键社死分享 |

## 设计取向

- **编辑感学术 × 黑色幽默暗色主义**：让产品同时具备「论文严肃」与「社死轻佻」两种对冲气质
- 字体系统：`Noto Serif SC` × `Instrument Serif` × `JetBrains Mono`
- 色彩：背景 `#0E0E10` + 骨白 `#F4F0E8`，四象限独立色（钢灰 / 苔绿 / 焦橙 / 血红）
- 动效：Catmull-Rom 曲线 morph 流体波形 / 打字机式 AI 输出 / 抢话震屏 / 数字 tick / 渐进揭晓

## 启动方式

```bash
cd MLGBTI-prototype
python3 -m http.server 7531
# 浏览器打开 http://127.0.0.1:7531/
```

或者直接双击 `index.html`（个别字体需联网；本地用 file:// 也可运行）。

## 演示路由（hash 直达，便于截图/路演）

| URL 后缀 | 跳转 |
|---|---|
| `#cover` | 首页 |
| `#brief` | 规则页 |
| `#battle` | 对线（自动开始三轮） |
| `#analyze` | 声纹解析 |
| `#result` | 随机一个 MLGBTI 确诊 |
| `#result?code=M2-L1-G2-B2` | 指定确诊（替换 code 即可） |

16 个 code：`M{1\|2}-L{1\|2}-G{1\|2}-B{1\|2}`，例如：
- 老油条·清醒牛马 `M1-L1-G1-B1`
- 高压锅·职场平头 `M2-L1-G2-B2`
- 精神病院·彻底疯狂 `M2-L2-G2-B2`

## 交互闭环

1. 首页 →【开始对线】
2. 规则页 →【进入对线】
3. AI 抛题 →（按住下方圆形按钮）→ 你说话 →（AI 抢话 / 静默 700ms 截断）
4. 三轮后自动进入解析 →
5. 确诊结果 →【一键分享让好友社死】或【不服 · 重测】
